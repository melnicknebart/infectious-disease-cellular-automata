# Data

The original course-supplied NYC map is intentionally not included in the public repository.

Run:

```bash
python generate_demo_map.py
```

to create a synthetic 150 × 150 grid at `data/demo_map.csv`.

If you have permission to use your map locally, place it at:

```text
data/nyc_map.csv
```

The `.gitignore` file excludes that filename so it is not accidentally published.
